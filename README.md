# DrOmar
Plataforma de nutrición y antropometría.

## MVP
Registro de pacientes, evaluaciones ISAK, historial y gráficos. El prototipo inicial usa datos ficticios en memoria; no utilizar con pacientes reales.

## Ejecutar
`cd frontend && npm install && npm run dev`

## Arquitectura objetivo
React/TypeScript, ASP.NET Core .NET 8, PostgreSQL, Railway y Cloudflare. Pendientes: autenticación, aislamiento por consultorio, persistencia segura, auditoría, consentimiento, importación PDF y validación profesional de fórmulas Kerr, Durnin-Womersley, Phantom y somatotipo.
